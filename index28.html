效果原理：bento grid 的每一格先用 CSS 給一個「出場位置」（往左、往上、縮小⋯⋯各自不同），外層拉高並用 sticky 把整片格子釘在畫面上；捲動進度換算成「應該有幾格已就位」，依序加上 class 讓 transform 歸零。因為每格的起始方向不同，組裝過程看起來像零件從四面飛回來，而不是整片一起淡入。
